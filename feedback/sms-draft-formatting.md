When drafting a text message for Emile to copy-paste and send (SMS, not email), put it inside a fenced code block (triple backticks), not as plain markdown paragraphs.

**Why:** Plain markdown paragraphs with blank lines between them collapse when copy-pasted into a texting app — the lines end up stacked with no spacing. A fenced code block preserves the exact blank lines on copy. Also, Emile can't manually add line breaks himself in his texting app since Enter sends the message — so the draft has to arrive pre-formatted with the spacing already correct.

**How to apply:** Any time a deliverable is a text/SMS message (as opposed to an email, which renders fine), wrap it in a code block with real blank lines between paragraphs. Don't use a period after a name-only signature line ("Emile, Duo Vert" not "Emile, Duo Vert."), and match how Emile actually addresses the person (e.g. first name if that's how he refers to them, not "M." if he calls them by first name).

**Never use "au plaisir de vous lire" (2026-08-20 correction):** Emile flagged this closing line as too literary/formal — "c'est comme si t'envoyais un message à un auteur", not something you'd text someone who just wants physical paver work done. **Why:** Duo Vert's texts go to regular clients about manual labor, not formal correspondence — the tone should be casual and warm, not literary. **How to apply:** use something simple and human instead, e.g. "on a hâte de vous rencontrer" / "content(e) de vous rencontrer" / "au plaisir !" — never the "vous lire" construction in any closing line, SMS or email.

**Be definitive about season capacity, not hedgy (2026-09-02 correction):** when telling a lead the project would happen next spring because Duo Vert is booked out for the rest of the season, state it as a fact ("on est complet pour le reste de la saison, donc le projet serait réalisé au printemps"), not a soft maybe ("ça se pourrait qu'on doive prévoir ça au printemps"). **Why:** Emile corrected a draft using the hedgy version - he wants the quote/visit offered confidently now, with the spring timing stated plainly, not floated as a possibility. **How to apply:** any outreach mentioning off-season timing should assert "we're booked out, so it'll be spring" directly, never "it might have to be spring."
