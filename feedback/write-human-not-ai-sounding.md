Default to writing that reads human-made, not AI-generated, across everything Claude writes for Emile — not just school work. Avoid the usual AI "tells": em dashes (already a hard rule, see [[feedback/no-em-dashes]]), generic AI cadence/phrasing, overly polished ad-copy tone when the context calls for something more casual. This is a standing style default, always on, not something to be asked for each time.

**Why (clarified 2026-09-02, correcting an earlier assumption):** After Claude built a full Cégep homework deliverable and Emile asked for it to be "untraceable by AI," Claude's first read was that this was about evading an academic-integrity/AI-detection check on graded work (see [[feedback/academic-integrity-boundary]]) — Emile corrected that read directly. His actual reasoning: most Cégep exercises done with Claude aren't even submitted — they're personal practice, not graded work, so there's nothing to "cheat" on. The real goal is deliberately practicing a human-sounding writing style *now*, using low-stakes school exercises as reps, because he'll need that same skill for real business content later — ads, Google Business Profile posts, personal-brand copy — where sounding AI-generated would actually hurt him. In his words: developing "AI skills" here specifically means training the habit of output that doesn't "sound AI," not avoiding detection on something dishonest.

**How to apply:**
- Treat this as a global default for all writing output, but apply it with extra deliberateness whenever the task is Cégep/school-related, since Emile has explicitly framed that context as his practice ground for this skill.
- This generalizes and supersedes the narrower per-content-type versions of the same idea already in memory — [[feedback/gbp-post-content-style]] ("sound human, not AI-generated... like a person actually wrote it") and [[feedback/sms-draft-formatting]] — those aren't special cases anymore, they're instances of this one standing rule.
- Don't reintroduce the "is this an academic integrity problem" framing for school work unprompted — Emile has explicitly said it isn't, most of it isn't submitted, and repeating that concern would be talking past what he actually asked for. [[feedback/academic-integrity-boundary]] should be read together with this note: the metadata-hygiene half of that memory still stands (clean Office file author metadata by default), but the "declined evading AI-content detection because of academic dishonesty" framing was Claude's own assumption, not something Emile confirmed — for future similar requests, default to this memory's read (skill-building) instead unless something about the specific situation actually points to graded/submitted work.
